## 📖 Overview

Everything you need in one window. Paste a link, press RIP, and let the pipeline do the work — from metadata lookup to a cleaned, ready-to-use model file.

- **📥 Free model downloads:** Download hi3d.ai models without paying or subscribing — just paste the model URL.
- **⚙️ One-click setup:** Install, launch, done. No server, no Python environment, no configuration files.
- **📐 Mesh optimization:** Deduplicate vertices and prune redundant geometry to keep every file small and clean.
- **🔄 Auto-retry pipeline:** Flaky connection? Turn on auto-retry and the pipeline keeps going until it succeeds.
- **👀 Built-in 3D viewer:** Every finished model opens in a showcase window so you can inspect it before using it.
- **🎮 Full control:** Stop a running job or rerun the same link at any time, without restarting the app.

## 🛠️ Installation

The whole process takes less than a minute on a standard Windows machine.

1.  **Download the installer**
    Grab `Hi3dRipperInstaller.exe` using the download button. It is a single Windows executable.

2.  **Run the installer**
    Double-click the file and follow the setup wizard. Installation completes automatically.

3.  **Start ripping**
    Open Hi3D Ripper, paste a hi3d.ai model URL into the input field, and press **RIP**.

> **Heads up:** Windows SmartScreen may warn about an unsigned installer. Choose **More info** → **Run anyway** to continue. The full source is available on GitHub if you prefer to inspect it first.

## 💻 Technical Details

Hi3D Ripper is a Windows desktop application designed to simplify the process of downloading and preparing 3D models from the hi3d.ai platform. It handles the entire pipeline from URL to a cleaned `.glb` file, ready for use in other 3D applications.
